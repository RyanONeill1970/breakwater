# Breakwater gameplay demo

The rendered video (`breakwater-gameplay-demo.mp4`) is kept out of git; it will be published as a GIF or on YouTube.

Recorded on 1 October 2026 from the main game, using scripted preview scenarios and the game's own sound. The footage runs at normal simulation speed; edits add cuts, chapter labels and brief opening/closing fades.

44 seconds, 1440 × 900, 30 fps, H.264 video and stereo AAC audio.

| Time | Scene |
| --- | --- |
| 00:00 | Modern island command and movement |
| 00:08 | Chase camera and combat on Operation Signal |
| 00:16 | Classic smoke and artillery support |
| 00:24 | Four-group command view |
| 00:32 | Daytime gunner sight |
| 00:38 | Night mission with thermal sight |

Recorded with Godot's `--write-movie` mode and existing QA preview switches. Preview runs use scratch saves. No gameplay code or player settings were changed to make this video.
